The standard normal (gaussian) kernel: `e^(-u²/2) / √(2π)`.

## Basic example

The standard normal density, `kernelDensity`'s default kernel. It takes the distance from an observation in bandwidths, peaks at about 0.3989, and never quite reaches zero.
