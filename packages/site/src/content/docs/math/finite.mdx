Whether a value is a finite number: not `NaN`, `±Infinity`, or a
non-number such as a numeric string, `null`, or an array.

## Basic example

True only for a number that is not `NaN` or infinite. A numeric string is not a number, so `"3"` is false; in TypeScript it also narrows the value to `number`.
