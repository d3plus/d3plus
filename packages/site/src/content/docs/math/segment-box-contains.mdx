Checks whether a point is inside the bounding box of a line segment.

## Basic example

Tests whether a point falls within the axis-aligned bounding box of a segment (dashed), not whether it lies on the segment itself. `segmentsIntersect` combines this with `lineIntersection` to confirm that a crossing point is actually on both segments.
