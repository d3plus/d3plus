The inverse cumulative distribution function (quantile) of Student's t-distribution: the t value below which a proportion `p` of the distribution lies.

## Basic example

The t value below which a proportion `p` of Student's t-distribution lies, for `df` degrees of freedom. `0.975` gives the critical value for a two-sided 95% interval: large with one degree of freedom, and converging on the normal distribution's 1.96 as `df` grows. `linearConfidence` uses it to size its band.
