Based on the defined styles and dimensions, breaks a string into an array of strings for each line of text.

## Basic example

`textWrap()` returns a generator: configure it, then call it with a string. `width(200)` is the only setting here, so the sentence is broken into as many 200px lines as it needs at the default 10px font, and `widths` reports the measured pixel width of each line.

<Calls code={basicExample} label="textWrap: Basic example" />

## Circle shape

`shape("circle")` limits each line to the chord of the circle at that line's height, so lines near the top and bottom are shorter than those through the middle. This is how labels fit inside Pack and Pie shapes.

<Calls code={circleShape} label="textWrap: Circle shape" />

## Font styling

`fontSize`, `fontWeight`, and `fontFamily` feed the measurement, so a bold 18px Inter line holds fewer words than the 10px default. The result re-measures once the web font has loaded.

<Calls code={fontStyling} label="textWrap: Font styling" />

## Max lines truncation

`maxLines(2)` keeps only the first two lines and sets `truncated: true` so a caller such as `TextBox` knows to add an ellipsis.

<Calls code={maxLinesTruncation} label="textWrap: Max lines truncation" />

## Ellipsis and cut words

`ellipsis` ends a truncated wrap's last line: a string to append, or a function `(text, line) => string`. The ended line is measured, and words come off its end until it fits the width. `truncateWord(true)` cuts the word that did not fit (or a first word wider than the line) to the longest start that fits with the ellipsis, between whole characters so an emoji is never split. `nextWord` is the index in `words` of the first word that did not fit.

<Calls code={truncateWord} label="textWrap: Ellipsis and cut words" />

## Words for justified text

`lineWords` splits each line into the units justified text spreads apart, a word with the spaces after it or a single CJK character or emoji, with their widths (not counting those spaces). `hardBreaks` marks the lines that end at a newline, which justified text leaves at the start. `TextBox` uses both for `textAnchor: "justify"`.
