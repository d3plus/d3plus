## Install

Pick your framework; the examples across the site follow your choice.

<Tabs syncKey="flavor">
  <TabItem label="JavaScript">
    ```sh
    npm install @d3plus/core
    ```
    Or load the bundle from a CDN, which defines a global `d3plus`:
    ```html
    <script src="https://cdn.jsdelivr.net/npm/@d3plus/core"></script>
    ```
  </TabItem>
  <TabItem label="React">
    ```sh
    npm install @d3plus/react
    ```
  </TabItem>
  <TabItem label="Vue">
    ```sh
    npm install @d3plus/vue
    ```
  </TabItem>
  <TabItem label="Svelte">
    ```sh
    npm install @d3plus/svelte @d3plus/core
    ```
  </TabItem>
  <TabItem label="Web Components">
    ```sh
    npm install @d3plus/element
    ```
  </TabItem>
  <TabItem label="Angular">
    ```sh
    npm install @d3plus/angular @d3plus/core
    ```
  </TabItem>
</Tabs>
