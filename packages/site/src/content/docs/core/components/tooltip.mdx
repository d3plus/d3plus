Creates HTML tooltips in the body of a webpage.

## Basic example

A tooltip is a small HTML panel positioned next to an element or a point. Give it `data` (one datum per tooltip), a `position` (a function returning an element, or `[x, y]` viewport coordinates), and call `render()`; render with empty data to hide it. By default the `title`, `body`, and `footer` sections read the fields of the same name from the datum. Here it points at the box in the middle; with coordinates, calling `render()` again moves the panel, and it keeps itself on screen, flipping below the point when there is no room above. Charts create one of these for you and expose its settings as `tooltipConfig`.
