Creates a dot plot from an array of data: each row draws as one dot at its
value along the `x` axis (or `y`), and the dots are swept into stacks one
dot wide (Wilkinson's dot-density algorithm), each stack at the mean of
its values. Set the other axis to a categorical key to stack each category
on its own row, `groupBy` to color the dots, `stackDirection` to center the
stacks, and `unit` to draw one dot per `unit` of a `value` column.

## Basic example

Every row is one dot. Sorted by value, the dots are swept into stacks one dot wide: the first value opens a stack, every value within one dot's width of it joins, and the stack is drawn at the mean of its values. The dots are as large as they can be while the tallest stack still fits the chart (up to 10 pixels); `dotRadius` fixes their size, and `binWidth` sets the stacks' width in data units instead.

## Groups as rows

Set the other axis to a categorical key and each category stacks on its own row, inside its band. A second `groupBy` level names each dot, so its tooltip shows the country.

<Playground chart="DotPlot" code={categoryRows} controls={["x","y","stackDirection"]} />

## Colored groups in one column

Without a category axis, `groupBy` colors the dots and every stack lists its groups in the same order, so the colors band across the stacks like a stacked histogram.

<Playground chart="DotPlot" code={coloredGroups} controls={["groupBy","dotRadius"]} />

## Centered stacks

`stackDirection: "center"` spreads each stack evenly on both sides of its row's center, for a symmetric, violin-like shape.

<Playground chart="DotPlot" code={centeredStacks} controls={["stackDirection"]} />

## Vertical rows

Swap `x` and `y` for vertical rows: the values run up the chart and the stacks grow to the right.

<Playground chart="DotPlot" code={verticalRows} controls={["x","y"]} />

## One dot per unit

With `unit`, a row's `value` becomes `round(value / unit)` dots, like a unit chart: here each dot stands for 50 people. A dot's tooltip names its row, its value, and what each dot stands for.
