Creates a ring visualization based on a defined set of nodes and edges.

## Basic example

`center` names the focal node by id; the rest of the nodes are inferred from the `links`, with the center's direct connections forming the inner ring and the others radiating outward.

<Playground chart="Rings" code={basicExample} controls={["center","links"]} />

## Larger network

Nodes one hop from the center sit on the inner ring; their neighbors fan out to an outer ring.

<Playground chart="Rings" code={largerNetwork} controls={["center"]} />

## Ring depth

`ringDepth` sets how many rings of connections surround the center: `1` shows only the nodes linked to it, and each step adds the next ring out, evenly spaced to the edge with smaller nodes. A node linked from several places sits once, on the innermost ring that reaches it, under its first parent. Clicking a node re-centers the chart on it.

<Playground chart="Rings" code={ringDepth} controls={["ringDepth","center"]} height={600} />

## Directional arrows

`arrows` draws an arrowhead at each edge's endpoint — following the bezier's tangent for the curved outer-ring links and insetting to the node for the straight center links. Use `"both"` or a per-link accessor for bi-directional edges.

<Playground chart="Rings" code={directionalArrows} controls={["arrows","arrowSize"]} />

## Sized nodes

`size` sizes every node, including the center, with one scale (square-root by default; see `sizeScale`), kept between `sizeMin` and `sizeMax`. A size legend in the corner shows what each radius means.

<Playground chart="Rings" code={sizedNodes} controls={["size","sizeMin","sizeMax","sizeScale","sizeLegend"]} height={500} />

## Link color and labels

`linkColor: "source"` colors each link and its arrowhead like the node it leaves (`"target"` like the node it enters, or a key or accessor to color links by a value). `linkLabel` writes a value halfway along each link; on the curved links between the rings (and parallel links, which fan out as curves) the text follows the curve. A label that would cover a node or another label is hidden.

<Playground chart="Rings" code={linkColor} controls={["linkColor","linkLabel","linkLabelConfig"]} />

## Self-loops

A link whose `source` and `target` are the same node draws as a loop on that node, wherever it sits: on the center, between the first ring's nodes, and on a ring node, beside it, clear of its label. A link from a node to itself never places a node on a ring.

<Playground chart="Rings" code={selfLoops} controls={["center","arrows"]} />
