Creates a Sankey visualization based on a defined set of nodes and links.

## Basic example

Supplying only `links` lets the layout infer every node from the `source`/`target` ids and route the flows between them.

<Playground chart="Sankey" code={basicExample} controls={["links"]} />

## Data driven link width

Each link's `value` sets its thickness, so flows are weighted by magnitude.

<Playground chart="Sankey" code={dataDrivenLinkWidth} controls={["value"]} />

## Node spacing

`nodeWidth` sets how thick each node bar is drawn and `nodePadding` the vertical gap between nodes in a column—raise `nodePadding` to spread crowded columns apart.

<Playground chart="Sankey" code={nodeSpacing} controls={["nodeWidth","nodePadding"]} />

## Directional arrows

`arrows` adds an arrowhead where each flow enters its target node, reinforcing the left-to-right direction. Use `"both"` for bi-directional flows or a per-link accessor.

<Playground chart="Sankey" code={directionalArrows} controls={["arrows","arrowSize"]} />

## Node labels

Each node is labeled beside it, over its outgoing flows, or over its incoming flows in the last column. A node too thin for a line of text, like Geothermal here, goes unlabeled. `label` sets the text, `shapeConfig.Rect.labelConfig` styles it, and `shapeConfig: {Rect: {label: false}}` turns the labels off.

<Playground chart="Sankey" code={nodeLabels} controls={["shapeConfig"]} />

## Link color and labels

`linkColor: "source"` colors each band like the node it leaves (`"target"` like the node it enters), drawn see-through so the bands it crosses show. A key or accessor colors bands by a value instead: numbers on the colorScale, strings as colors or categories. `linkLabel` writes a value at the middle of each band, along it or level (`linkLabelConfig.rotate`); a label that would cover a node or another label is hidden, the widest bands' labels kept first.

<Playground chart="Sankey" code={linkColor} controls={["linkColor","linkLabel","linkLabelConfig"]} />
