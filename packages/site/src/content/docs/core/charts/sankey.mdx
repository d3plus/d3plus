Creates a Sankey visualization based on a defined set of nodes and links.

## Basic example

Supplying only `links` lets the layout infer every node from the `source`/`target` ids and route the flows between them.

## Data driven link width

Each link's `value` sets its thickness, so flows are weighted by magnitude.

## Node spacing

`nodeWidth` sets how thick each node bar is drawn and `nodePadding` the vertical gap between nodes in a column—raise `nodePadding` to spread crowded columns apart.

<Playground chart="Sankey" code={nodeSpacing} controls={["nodeWidth","nodePadding"]} />

## Node labels

Each node is labeled beside it, over its outgoing flows, or over its incoming flows in the last column. A node too thin for a line of text, like Geothermal here, goes unlabeled. `label` sets the text, `shapeConfig.Rect.labelConfig` styles it, and `shapeConfig: {Rect: {label: false}}` turns the labels off.

<Playground chart="Sankey" code={nodeLabels} controls={["shapeConfig"]} />

## Link color and labels

`linkColor: "source"` colors each band like the node it leaves (`"target"` like the node it enters), drawn see-through so the bands it crosses show. A key or accessor colors bands by a value instead: numbers on the colorScale, strings as colors or categories. `linkLabel` writes a value at the middle of each band, following its curve or level (`linkLabelConfig.rotate`); a label that would cover a node or another label is hidden, the widest bands' labels kept first.

<Playground chart="Sankey" code={linkColor} controls={["linkColor","linkLabel","linkLabelConfig"]} />

## Nodes without links

Every entry in `nodes` is drawn, including nodes that no link touches. Such a node has no flow to size it, so it takes `value` read from its own row in `nodes` when that is a positive number ("reserve" here), and otherwise the value of the thinnest link ("pending"). With the default `nodeAlign`, it sits in the first column, with the sources.

<Playground chart="Sankey" code={unlinkedNodes} controls={["nodes","value","nodeAlign"]} />

## Flows that loop back

A flow that returns to a node it already left can't run left to right, so Sankey draws it as a circular band: it leaves its source's right side, turns up or down, runs along a lane above or below the nodes, and turns back into its target's left side. Here recycled material returns to raw materials and manufacturing, and manufacturing reworks some of its own output (a link from a node to itself). On a loop through several nodes, the lightest link is the one drawn this way. A band runs above the nodes when its two ends sit in the upper half of the chart, else below; shorter loops nest inside longer ones, and the chart makes room for the lanes so none is cut off at its edge. Each node is as tall as the flow through it, returns included. Circular bands take `linkColor`, `linkLabel` (on the lane), tooltips, and focus like the others; `circularLinks: false` leaves them out instead and logs a warning naming them.

<Playground chart="Sankey" code={circularLinks} controls={["circularLinks","linkColor"]} />

## Network measures

Hovering a node lists its in-degree and out-degree (the flows into and out of it), betweenness, and closeness, with paths that follow the flows from source to target. `nodeTooltipStats` picks the measures or turns them off, and `nodeTooltipStatsConfig.weighted` counts a larger `value` as a shorter step; see [Network measures](/core/charts/network/#network-measures).
