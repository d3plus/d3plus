Creates a scatter plot from an array of data: each row draws as a point at
its `x` and `y` values, on continuous axes. Text values on an axis (on
both, the one with fewer distinct values) make it a category axis, as
`discrete` does, which also sets it explicitly. Points are `sizeMin` pixels in radius; a `size`
accessor scales them between `sizeMin` and `sizeMax` and adds a size
legend (see BubbleChart for bubbles sized by area). Hover any point for
its values.

## Basic example

Each row draws as a point at its `x` and `y` values, on two continuous axes. Grouping by `species` first colors the points by species and adds a legend; hover any point for its values.

<Playground chart="Scatter" code={basicExample} controls={["x","y","groupBy"]} />

## Category axis

When the `x` or `y` values are text, that axis is the chart's discrete axis, exactly as if `discrete` named it: one position per category in data order, an untitled axis, a badge on it for the hovered category, and a shared tooltip listing every series in the hovered column. Numbers stored as text, like `"2019"`, stay continuous. When both axes hold text, the one with fewer distinct values is the category axis (`x` on a tie); set `discrete` to choose the axis yourself.

<Playground chart="Scatter" code={categoryAxis} controls={["x","discrete"]} />

## Sized points

A `size` accessor scales each point's radius between `sizeMin` and `sizeMax` and adds a size legend. To size points by area, so a value twice as large draws twice the area, use BubbleChart.

<Playground chart="Scatter" code={sizedPoints} controls={["size","sizeMin","sizeMax"]} />

## Trend line

Set `trendLine: true` to fit a least-squares line to each series (here each `species`), drawn behind the points. Hover a line for its equation and R².

<Playground chart="Scatter" code={trendLine} controls={["trendLine","trendLineConfig"]} />

## Point labels

Points too small to hold their label get it beside them instead, on the side facing the most open room (the point's Voronoi cell), where it overlaps no other point or label and stays inside the plot. Where the points crowd together there is no such room, so those labels hide; hover a point for its name. `labelPosition: "inside"` keeps labels inside the points, and `pointLabelConfig` sets the size and style of the labels beside them.

<Playground chart="Scatter" code={pointLabels} controls={["labelPosition","pointLabelConfig"]} />

## Connected points

`order` names the field that orders each series' points, here the year. A line joins each country's points in that order, so it can double back when a measure falls, with an arrowhead on each segment pointing along the path and the first and last years labeled. [ConnectedScatter](/core/charts/connected-scatter/) draws the same chart.

<Playground chart="Scatter" code={connectedPoints} controls={["order","pathArrows","pathLabels"]} />

## Jittered categories

On a category axis (text values, or `discrete: "x"`), points that share a category and a value would hide each other. `jitter: true` spreads them across 0.6 of their category's band (a number sets another share), each by an offset seeded from its id, so a point never jumps between draws. StripPlot is a Scatter with this on by default.

<Playground chart="Scatter" code={jitter} controls={["jitter","discrete"]} />

## Error bars

`confidence` names each point's lower and upper bounds, drawn as a capped error bar through the point; the y axis widens to fit them, and the tooltip lists them. A label beside its point keeps clear of every error bar, and hides when no side is clear; hover a point for its name.

<Playground chart="Scatter" code={errorBars} controls={["confidence","confidenceConfig"]} />

## Error bars on both axes

Give `confidence` an object, `{x: [lower, upper], y: [lower, upper]}`, to bound each axis: a point with both draws a cross. Each axis widens for its own bounds, and the tooltip lists both, named for their axes. Style the bars with `confidenceConfig` (or `confidenceConfig.Circle` for points alone), and `capWidth` for the caps, which match each point's width by default.

<Playground chart="Scatter" code={errorBarsBothAxes} controls={["confidence","confidenceConfig"]} />

## Log axes

Body and brain masses span several orders of magnitude, so both axes are `scale: "log"`. A log axis draws short, unlabeled minor ticks at 2 through 9 times each power of ten (thinned to 2 and 5, or left off, where they would crowd), and `minorGrid: true` runs fainter grid lines from them across the plot (`minorGridConfig` styles them). `minorTicks: false` turns the minor ticks off.

<Playground chart="Scatter" code={logAxes} controls={["xConfig","yConfig"]} />

## Marginal distributions

`marginals: "histogram"` draws each axis's distribution beside the plot: the x values in a strip above it and the y values in a strip to its right, each lined up with its axis. The points split by legend entry, stacked in their colors, and only the points the chart shows are counted, so hiding a species in the legend (or moving the timeline) redraws the strips. Hover a point to light the bins holding it, or a bin for its range and count and to light its points.

<Playground chart="Scatter" code={marginalHistograms} controls={["marginals","marginalConfig"]} />

## Box plots and density curves

`"box"` draws a box plot per series and `"density"` a kernel density curve per series, each scaled by its share of the points. Give `marginals` an object, `{x, y}`, to pick each strip, and leave one out to draw only the other. `marginalConfig` sets each strip's `size` (pixels, or a share of the chart area's shorter side; `0.15` by default), its `padding` from the plot, and a histogram strip's `binThresholds`. Strips need two continuous axes, so a chart with a category axis draws none.

<Playground chart="Scatter" code={marginalDistributions} controls={["marginals","marginalConfig"]} />
