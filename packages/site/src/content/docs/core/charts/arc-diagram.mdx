Places a network's nodes in a row along one line and draws each link as
an arc between its two nodes, which shows the network's structure
without a force layout's tangle, in an order you choose.

## Basic example

Takes the same `nodes` and `links` as Network. Nodes sit evenly along one line in their `nodes` order, and each link arcs between its two nodes: the farther apart the nodes, the taller the arc.

<Playground chart="ArcDiagram" code={basicExample} controls={["nodes","links","orient","arcSide"]} />

## Sort by group

`nodeSort: "group"` gathers each team together (by the `color` value, then by label), so links within a team draw as small, low arcs and the few links between teams stand out as the tall ones. `"label"`, `"degree"` (most connected first), or a comparator reorder the line too. `linkSize` sets each arc's thickness from the number of meetings.

<Playground chart="ArcDiagram" code={sortByGroup} controls={["nodeSort","color","linkSize"]} />

## Clusters

With no colors of its own, an ArcDiagram colors its nodes by cluster as [Network does](/core/charts/network/#clusters): the Louvain method finds the groups of nodes linked more to each other than to the rest, weighted by `linkSize`, and names each after its most-connected node. The legend lists the clusters largest first (at most `clusterConfig.max`, 12 by default), and clicking one focuses it. `nodeSort: "group"` orders the line by cluster, so each cluster's arcs stay short. An ArcDiagram names its clusters in the legend only. Set `cluster` to `false` for one color per node.

<Playground chart="ArcDiagram" code={clusters} controls={["cluster","nodeSort"]} />

## Directed arrows

`arrows` draws an arrowhead where each arc meets its target node (`"source"`, `"both"`, or an accessor pick other ends), pointing along the arc.

<Playground chart="ArcDiagram" code={directedArrows} controls={["arrows","arrowSize"]} />

## Both sides

`arcSide: "both"` arcs each link running forward along the line above it, and each link running back below it, so loops back to earlier steps read apart from the forward flow. The node labels sit under the line, where the backward arcs pass behind them, so each draws over a halo in the chart's background that keeps it readable; with `arcSide: "below"` the labels move above the line, clear of every arc. `linkColor: "source"` colors every arc like the node it leaves.

<Playground chart="ArcDiagram" code={bothSides} controls={["arcSide","arrows","linkColor"]} />

## Link color and labels

`linkColor` also takes a key or accessor: numbers color the arcs on the colorScale, and strings are colors or categories (links with no value keep the theme's gray). Here the rework loops are drawn in orange. `linkLabel` writes a value along the top of each arc, following its curve (and around the far side of a loop), hidden when it would cover a node or another label.

<Playground chart="ArcDiagram" code={linkLabels} controls={["linkColor","linkLabel","linkLabelConfig"]} />

## Self-loops

A link whose `source` and `target` are the same node draws as a small loop on the arcs' side of the line (above it with `arcSide: "both"`), pointing straight out from the node. Several loops on one node fan out side by side. Loops take `linkSize`, `linkColor`, `linkLabel`, and `arrows` like the arcs, and have the same tooltip, hover, and focus.
