Draws a Venn diagram from rows that each name one or more sets (`sets`) and
a size (`value`, read from `size` by default). A row with one set is that
set's circle; a row with several is the region where those sets overlap,
and its size counts the items in every one of them. By default the circles
and their overlaps are sized to their values, and each region is labeled
with its count. Hover a region to see its exact intersection.

## Basic example

Three sets with every overlap. Each circle's area matches its set's size
and each overlap's area its row's size, as closely as circles allow. The
labels count what falls only in each region (Python alone: 540 − 260 − 120
+ 70 = 230), so they add up to everyone. Hover an overlap to highlight it
and the smaller overlap inside it; its tooltip shows its whole size and the
count in it alone. The legend lists the sets: hover one to highlight its
circle, or click it to hide the set and every overlap it is part of.

## Classic layout

`proportional: false` draws the textbook arrangement, whatever the sizes,
in which every combination of sets has a region of its own: equal circles
side by side for two sets or in a triangle for three. The labels still
carry the counts.

<Playground chart="Venn" code={classicLayout} controls={["proportional"]} />

## Four and five sets

Circles can't show every combination of four or more sets, so with
`proportional: false` four sets take Venn's four ellipses and five sets
Grünbaum's five symmetric ellipses: all 15 or 31 combinations appear, each
labeled at its deepest point and highlighted on hover. Six or more sets
fall back to a ring of equal circles, where not every combination appears.

<Playground chart="Venn" code={fourSetsClassic} controls={["proportional"]} />

## Euler diagram

Sets that share nothing are drawn apart, and a set whose overlap with
another is as large as itself is drawn inside it, so the same data makes
an Euler diagram. A circle inside another is labeled with its own name.

<Playground chart="Venn" code={eulerDiagram} controls={["proportional"]} />

## Inclusive counts and colors

`labelCounts: "inclusive"` labels each region with its row's own size
rather than the count in it alone. Each set takes its color from `color`,
and each overlap blends the colors of its sets.

<Playground chart="Venn" code={inclusiveCounts} controls={["labelCounts","color"]} />

## Custom keys

`sets` and `value` read the sets and sizes from other keys (or accessor
functions); a row of one set may name it on its own instead of in an
array. `valueFormat` formats the counts in labels and tooltips.

<Playground chart="Venn" code={customKeys} controls={["sets","value","valueFormat"]} />
