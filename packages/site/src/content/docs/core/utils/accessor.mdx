Wraps an object key in a simple accessor function.

## Basic example

Turns a key into the function `d => d[key]`. Every chart config that accepts "a key or an accessor" (`groupBy`, `x`, `y`, `sum`, `label`, …) runs string values through this, so the rest of the pipeline only ever deals with functions.

<Calls code={basicExample} label="accessor: Basic example" />

## Default value

A second argument is returned whenever the key is `undefined` on a row, which is how optional config such as `x` or `y` fall back to `0` for rows missing the field.
