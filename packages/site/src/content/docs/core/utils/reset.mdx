String constant used to reset an individual config property.

## Basic example

A sentinel string that any config value can be set to. `config()` treats it as "restore the default", which matters because a chart keeps every setting it was ever given; passing `undefined` would leave the old value in place. It works at any depth, so `shapeConfig: {fill: RESET}` resets just the fill.

## Live example

The same Legend instance is told to draw circles, then given `RESET` for that one key. Tick the box to watch the swatches return to the default rectangles while the data, colors, and size stay as configured.
