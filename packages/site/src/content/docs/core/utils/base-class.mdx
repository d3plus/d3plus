Provides shared configuration, event handling, and locale management inherited by all d3plus classes.

## Reference

`BaseClass` supplies the fluent API shared by every class: `config()` for deep-merging a settings object (with `RESET` to restore defaults), `on()` for event handlers, `locale()` for translations and number formats, and `translate()` for localized strings. A subclass only has to define getter/setter methods; `config()` discovers and calls them.
