Creates SVG rectangles based on an array of data.

## Basic example

Three rectangles centered on their `x`/`y` with data-bound `width`/`height` and a per-datum `fill`.

<Playground chart="Rect" code={basicExample} controls={["width","height"]} />

## Labels

`label` returns the text drawn inside each rectangle (a newline splits it into lines) and `labelConfig` is a TextBox configuration for it, so font size, color, and alignment follow the same keys as a standalone TextBox. Labels that do not fit are hidden rather than overflowing.
