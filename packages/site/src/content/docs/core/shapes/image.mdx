Creates SVG images based on an array of data.

## Basic example

A single datum places one image at its `x`/`y` at the given `width`/`height`; the `url` accessor here points to an inline SVG data URI.

<Playground chart="Image" code={basicExample} controls={["url"]} />

## Multiple images

One image per datum, each sized by its own `width` and `height` and centered on its `x`/`y`; `opacity` fades the third. Geomap and Network use this shape for icons and flags.
