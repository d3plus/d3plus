The key a chart's data cache stores a load under: the loader key (`data`,
`links`, `nodes`, `topojson`, `fitObject`) plus the JSON of every path in the
request, so a request object's `fetch` options and each URL of a list are part
of it. A single path and a one-item Array of it share a key.

## Basic example

Each chart keeps the responses it fetches (see the `cache` config key) under
these keys. A URL and a one-item Array of it match, while a different loader,
different headers, or another list of URLs each get their own entry.
