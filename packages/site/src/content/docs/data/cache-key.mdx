The key a chart's data cache stores a fetched response under: the JSON of the
URL or request object, so a request object's `fetch` options are part of it.
Every loader (`data`, `links`, `nodes`, `topojson`, `fitObject`) shares these
keys, so two loaders naming the same request share one response.

## Basic example

Each chart keeps the responses it fetches (see the `cache` config key) under
these keys. The same URL always matches, while different headers or another
URL each get their own entry.
