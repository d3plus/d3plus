# Interactivity

D3plus charts are interactive out of the box: hovering a shape highlights it and
shows a tooltip, and a legend lets viewers toggle series. Everything below works
identically on the SVG and Canvas backends.

## Tooltips

Tooltips are on by default. Turn them off with `tooltip: false`, or customize
their contents and styling with `tooltipConfig` (a
[Tooltip](/?path=/docs/core-components-tooltip--docs) configuration):

```jsx
<BarChart config={{
  data, groupBy: "region", x: "quarter", y: "revenue",
  tooltipConfig: {
    title: d => d.region,
    tbody: [
      ["Quarter", d => d.quarter],
      ["Revenue", d => `$${d.revenue}M`]
    ]
  }
}} />
```

## Pointer events

Register handlers through the `on` config key. Event names mirror
[d3-selection](https://github.com/d3/d3-selection#selection_on) and may carry a
namespace to scope the handler — `.shape` for data marks, `.legend` for legend
entries:

```jsx
<BarChart config={{
  data, groupBy: "region", x: "quarter", y: "revenue",
  on: {
    "click.shape": d => console.log("clicked", d),
    "mouseenter.shape": d => console.log("hover", d)
  }
}} />
```

Supported events include `click`, `mouseenter`, `mouseleave`, and `mousemove`.
The handler receives the datum; `this` is bound to the rendered element.

## Highlighting a series

`highlight` applies a *standing* emphasis: pass a predicate and every matching
mark keeps its color while the rest fade to a neutral gray. Unlike `hover` or
`active`, it persists — it doesn't clear when the pointer moves — so it's ideal
for drawing attention to one series:

```jsx
<BarChart config={{
  data, groupBy: "region", x: "quarter", y: "revenue",
  highlight: d => d.region === "North"   // North stays colored; others gray out
}} />
```

Pass `false` or `null` to clear the highlight. See the
[BarChart highlight example](/?path=/docs/core-charts-barchart--docs).

## Legend

A legend is shown automatically for grouped data. Clicking an entry toggles that
series; hovering highlights it. Control it with `legend` and `legendConfig`:

```jsx
<BarChart config={{
  data, groupBy: "region", x: "quarter", y: "revenue",
  legend: true,                 // false to hide
  legendConfig: {title: "Region"}
}} />
```

## Timeline

Adding a `time` accessor enables a timeline beneath the chart. Viewers can scrub
or play through time periods, and the chart filters to the selected window:

```jsx
<LinePlot config={{
  data,                          // rows that include a "year" field
  groupBy: "series",
  x: "year", y: "value",
  time: "year",
  timelineConfig: {playButton: true}
}} />
```

Set `timeline: false` to keep the `time` filtering behavior without rendering the
timeline control.

When points move between periods as the timeline plays, they leave **motion
trails** by default, and `trailPersist` can keep the whole path visible. See
**Guides → Animation**.

## Zoom & pan

Every chart zooms and pans its content by default, with controls in the
chart's top-right corner (zoom in, zoom out, reset, and a drag-to-zoom brush
that ends after one selection), wheel zoom, and drag-to-pan.

Charts leave page scrolling alone: Ctrl/⌘ + wheel (or a trackpad pinch)
zooms, a plain wheel scrolls the page, and on touch screens one finger
scrolls while two fingers pinch-zoom — one finger pans only once the chart is
zoomed in. Geomap and Network are pan-and-zoom surfaces, so they zoom on any
wheel. Set `zoomScroll` to `true` (any wheel), `"modifier"`, or `false` (no
wheel zoom) to choose. A title,
subtitle, total, or top/right legend wraps or shifts to leave room for the
controls. Set `zoom: false` to turn it all off. Zoomed content is clipped to
the chart area, so the legend, title, and timeline stay put.

The control buttons are real `<button>`s: the brush toggle carries
`aria-pressed` and an `.active` class while on, and by default paints the OS
accent color. Set `zoomControlClassName` to style them with your own CSS.

Plot-based charts (BarChart, LinePlot, AreaPlot, StackedArea, BoxWhisker,
BumpChart, and Plot itself) zoom their data instead of the picture: each
linear axis stays in place and rescales its domain, while category, time, and
log axes stay fixed. A bar chart zooms and pans along its value axis only; a
scatter plot with two linear axes zooms in both directions.

How far you can zoom in adapts to what's drawn:
by default, the limit is the scale at which the chart's smallest shape fills
the chart area (a line or area series counts each segment between points), so
a few large shapes allow little zoom while a detailed map zooms all the way
into its smallest path. Set `zoomMax` to fix the limit instead. Tune the rest
with `zoomFactor`, `zoomScroll`, `zoomPan`, and `zoomPadding` — see the
[Geomap](/?path=/docs/core-charts-geomap--docs) examples for custom zoom,
disabling zoom, and zoom limits.
