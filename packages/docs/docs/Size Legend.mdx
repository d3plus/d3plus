# Size Legend

When a chart sizes its marks by a value, such as bubbles in a scatter plot, points on a map, or nodes in a network, a **size legend** in the chart's bottom-right corner shows what those sizes mean. It draws a set of concentric circles that share a bottom edge, under a centered title, with a short leader line from the top of each circle to a label giving the value it represents.

The legend's circles are drawn with the chart's own radius scale, so they are exactly the sizes of the chart's marks: the largest circle matches the largest mark.

## When it appears

The size legend is on by default. It appears whenever a chart sizes its marks by more than one distinct value, unless it would take up more than a third of the chart's width or height. Very large bubbles in a small chart would otherwise leave no room for the chart itself:

| Chart | Sized by | Radius settings |
| --- | --- | --- |
| Plot family (bubble / scatter) | `size` | `sizeMin`, `sizeMax`, `sizeScale` |
| Geomap coordinate points | `pointSize` | `pointSizeMin`, `pointSizeMax`, `pointSizeScale` |
| Network | `size` | `sizeMin`, `sizeMax`, `sizeScale` |
| Rings | `size` | `sizeMin`, `sizeMax`, `sizeScale` |

When `size` is set to a data key (`size: "population"`), that key becomes the legend's title.

Set `sizeLegend` to `true` to always show it, or to `false` to hide it. It also accepts a function that returns whether to show the legend. The function receives the resolved chart config, the radius scale, and the legend's measured `{width, height, availableWidth, availableHeight}`:

```jsx
<Plot config={{data, groupBy: "id", x: "x", y: "y", size: "value", sizeLegend: false}} />
```

## Configuring it

Pass options to the legend with `sizeLegendConfig`:

```jsx
<Plot config={{
  data, groupBy: "id", x: "x", y: "y", size: "revenue",
  sizeLegendConfig: {
    title: "Revenue ($M)",
    values: [100, 1000, 2000],        // which circles to draw (or a count, default 3)
    tickFormat: d => `$${d}M`,        // label format (default: abbreviated numbers)
    shapeConfig: {fill: "#4269d0", fillOpacity: 0.1, stroke: "#4269d0"},
    lineConfig: {strokeDasharray: [2, 2]},
    labelConfig: {fontSize: 12},
    titleConfig: {fontWeight: 700}
  }
}} />
```

By default the legend draws three circles, for the smallest value, the largest value, and a round value in between. The smallest and largest are the actual extremes of the data, so those circles match the chart's smallest and largest marks. Labels that would overlap are pushed apart.

## Placement

The legend sits in the chart's **bottom-right corner**, in a panel that the chart measures and reserves before it lays out. `sizeLegendPosition` picks which margin that panel takes:

- **`"right"`** (the default) widens the right margin, so the chart keeps its full height. The legend sits at the bottom of the right column, and a right-side legend or colorScale shortens to end above it. A bottom legend or colorScale narrows to stay clear of that column.
- **`"bottom"`** deepens the bottom margin instead, so the chart keeps its full width. A bottom legend or colorScale narrows to sit beside it, and a right-side one still ends above it.

```jsx
<Plot config={{data, groupBy: "id", x: "x", y: "y", size: "value", sizeLegendPosition: "bottom"}} />
```

A timeline always stays below the legend. See the [Plot size legend](/?path=/story/core-charts-plot--size-legend) and [size legend config](/?path=/story/core-charts-plot--size-legend-config) stories.

## Zooming

Geomap points, and Network and Rings nodes, grow as you zoom in. The legend doesn't grow with them. Instead it keeps its circles the same size and relabels them with the values those circle sizes now represent on screen, rounded to a clean number. The legend stays accurate at every zoom level and always fits in its corner. Try zooming the [Geomap point size legend](/?path=/story/core-charts-geomap--point-size-legend) story.

Plot charts zoom by rescaling their axes, and their bubbles keep the same size, so their legend doesn't change when you zoom.

## Standalone

The legend is also available as its own component, `SizeLegend`. Give it any d3 continuous scale that maps values to pixel radii:

```js
import {SizeLegend} from "@d3plus/core";
import {scaleSqrt} from "d3-scale";

new SizeLegend()
  .scale(scaleSqrt().domain([0, 1000]).range([2, 30]))
  .title("Population")
  .select("#legend")
  .render();
```

See the [SizeLegend](/?path=/docs/core-components-sizelegend--docs) component page for more examples.
